# Installation

## Requirements

- Python 3.10+

## Install

```bash
pip install goga-tool-scriba
```

## Documentation dependencies

To build documentation locally:

```bash
pip install -e ".[docs]"
```

This installs `mkdocs>=1.6.0` and `mkdocs-material>=9.5.0`.

## Local docs preview

```bash
mkdocs serve
```
